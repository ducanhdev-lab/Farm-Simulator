# Build & ship — Island Harvest

## Android APK (portfolio)

1. Open project in **Unity 6000.3.10f1**.
2. **File → Build Settings → Android** → Switch Platform.
3. Player Settings:
   - Package: `com.islandharvest.game`
   - Minimum API 28, ARM64
4. **Build** → output `Builds/Android/IslandHarvest.apk` (folder is gitignored).
5. Upload APK to [itch.io](https://itch.io) or Google Drive; paste link in `README.md`.
